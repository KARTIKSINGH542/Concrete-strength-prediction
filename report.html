Why This Step?

Duplicate rows are a form of data leakage — if the same mix appears in both training and test sets, the model looks better than it truly is. Removing 25 duplicates ensures the test set reflects genuine generalisation.

Step 05

Outlier Detection & Removal (Z-Score)

Z-score based outlier detection was applied to all 8 input features. Any sample where at least one feature had |Z| > 3.5 was removed as physically implausible.

from scipy.stats import zscore

feat_cols = ["Cement","BFS","FlyAsh","Water","SP","CoarseAgg","FineAgg","Age"]
z_scores = np.abs(zscore(df[feat_cols]))

# Keep only rows where ALL features have |Z| < 3.5
df = df[(z_scores < 3.5).all(axis=1)].reset_index(drop=True)
# Clean dataset: 2,891 rows (114 outliers removed)
Why threshold = 3.5? We chose 3.5 to be conservative — removing only near-certain measurement errors or physically impossible mixes, while preserving valid high-strength designs.
Step 06

Feature Engineering — Water-to-Binder Ratio

W/B = Water / (Cement + BFS + FlyAsh)
# Cement + BFS + FlyAsh = total binder content
df["WB_ratio"] = df["Water"] / (df["Cement"] + df["BFS"] + df["FlyAsh"])
Why This Step?

Abrams' Law (1919) states that concrete strength is inversely proportional to the w/c ratio. By encoding this as a feature, we give every model direct access to the physically meaningful ratio.

Step 07

Train / Test Split — 80:20

The clean 2,891-sample dataset was split into training (80%) and test (20%) sets using a fixed random seed. This is performed before any feature scaling.

❌ Wrong Order

  • Scale ALL data → then split
  • Scaler sees test set statistics
  • Test data leaks → inflated R²

✅ Correct Order

  • Split first → then scale
  • Scaler sees ONLY training statistics
  • Genuine unseen evaluation
Step 08

Min-Max Normalisation — No Data Leakage

All 9 input features were scaled to [0, 1] using Min-Max normalisation. The scaler was fit exclusively on training data, then applied to both sets.

scaler = MinMaxScaler()

X_train = scaler.fit_transform(X_train)  # fit + transform on TRAIN only
X_test  = scaler.transform(X_test)        # transform ONLY — no refit
Why Min-Max? Min-Max preserves exact zeros in BFS, FlyAsh, and SP columns — Z-score would shift those zeros away, losing physical meaning. It also brings heavily skewed units into a standard scale for SVR.
